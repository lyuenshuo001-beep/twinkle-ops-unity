## 范围与限制

本轮地图增加接待区、诊疗室、跨区室内运输廊、车库第二出口、屋顶步梯/桥梁。真实 CC0 厂房门窗模块及 PBR 材质，原建筑碰撞/楼梯保留。天空使用 CC0 日间 HDRI。34 个六类容器、2 个保险箱，六档品质沿用不同容器掉落表。

经济为单机本地系统：2×2 安全箱、买药、战前装包、物资出售、仓库排序、收益/损失结算。完整枪械商店、护甲弹药等级、改枪、钥匙房、任务、市场、多人/PVPVE 未实现。M4A1/AKM/M9/M870 沿用；本轮没有用换名凑 MP5/M24/M700/M249。感染者外观仍为同一基础模型的变体，枪械/手部动作主要为程序动画，地图细节仍有明显 Alpha 水平。

命中尘埃/弹痕采用固定池；无爆炸武器，因此不宣称完成爆炸烟雾系统。图标为项目原创示意图；拖拽支持背包内移动/旋转及与安全箱互转，容器拾取使用按钮。背包与菜单不会暂停战斗。

GitHub Pages 中国大陆网络质量未做地区实测；备用静态托管流程见 DEPLOYMENT.md，尚未配置第二个服务账号。浏览器仓库不跨设备同步。

浏览器搜索补充：使用真实鼠标转向、W 键走近物资箱、E 键打开；已检查 Logs/v12-browser-search-start.png 的未知物品转圈，以及 v12-browser-search-picked.png 的实际工具入包（2.4 kg / ¥850）。

搜索浏览器验收采用 Tools/BrowserSearchReview.cjs 保持同一会话，按截图逐步转向/移动/按 E/拾取。固定延时移动的脚本在软件 WebGL 下瞄准不稳定，已替换为此复核工具，没有将失败脚本算作通过。启动日志仍有与 V1.1 相同的附加光格式/FSR 回退、池对象初始创建位置的 NavMesh 警告；这里的零异常不代表零警告。对象池实际重定位和追击由 PlayMode 另行验证。
